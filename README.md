# Minecraft-Server-Manager

A lightweight Windows manager for hosting, configuring, and maintaining a Minecraft server.

## Features
- Start, stop, and restart the Minecraft server cleanly
- Automated world and configuration backups
- Easy server configuration and log monitoring
- Remote access support (e.g., over Tailscale or port forwarding)

## Requirements
- **OS:** Windows 10 or Windows 11 (Windows only)
- **Memory (RAM):** 4 GB minimum (8 GB+ recommended for larger worlds or mods)
- **Java:** Java 17, Java 21, or Java 25 (depending on your Minecraft server version)
